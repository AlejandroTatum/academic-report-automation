# Format - APE, AA or libre

Executor: document-workflow
Artifact: `reports/<wf>/report.yml`

Ask the user the single question - APE, AA or libre - and record `format:`
plus that format's required metadata in `report.yml` (`libre` also needs a
`format_spec:`). Every format builds with biblatex IEEE style; `ape` and `aa`
map to the academic route, `libre` to the user's spec on the plain template.
Never invent the answer or fill identification fields on the user's behalf.
