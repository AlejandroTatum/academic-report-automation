# Evidence matrix template

Complete one row per reusable claim. Duplicate rows when one claim relies on multiple sources. Every source-inventory and matrix entry must record source eligibility/status. Keep URLs/DOIs and quoted text exact; use `Unknown` only with an explanation in limitations.

| Claim ID | Claim | Source | Source type | Source eligibility/status | Publication date | Source locator | Verbatim evidence | Support / paraphrase note | Confidence | Limitations / contradiction | Citation key |

| C-001 |  |  |  | `eligible` — local `inspected: true`; otherwise `lead` |  | URL, DOI, page, section, table, or timestamp |  | Quote, or `Paraphrase — verify against source` | High / Medium / Low |  |  | |

## Source eligibility/status

- `eligible`: local source with `inspected: true`; it may appear in final citations and the bibliography-ready handoff.
- `lead`: a local uninspected source or an externally discovered but unverified source. It is not bibliography-eligible until inspected and provenance-complete.
- Keep leads visible in a separate follow-up list; do not include them in the bibliography-ready handoff.
